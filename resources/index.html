Room note / 01

The first 20 minutes of rehearsal should not be a meeting.

The most expensive part of rehearsal is often the beginning: time spent remembering what was decided, deciding what to play, and finding the current version. A rehearsal plan does not need to be elaborate. It needs to be shared before anyone has unloaded an amp.

Name the one thing the room is for.

Give the rehearsal a visible job. It might be a bridge that keeps rushing or a harmony entrance that needs a decision. One sentence gives everyone a reason to arrive prepared.

Make the version explicit.

Identify the recording, chart, key, cue, and ending that count today. A band can survive a wrong note. It struggles with five plausible versions of the same arrangement.

Give every player a small arrival task.

A specific focus gives each person a reason to prepare without making rehearsal feel like homework.

Use this next time
  • Confirm who is in the room.
  • Name the song or set section that matters tonight.
  • Link the current version, key, and ending.
  • Write down one decision you must not lose afterward.

Stage note / 02

The 15-minute gig-prep check.

A good gig can be derailed by small uncertainty: an unconfirmed key, a buried chart, a last-minute set re-order, or a player who never saw the arrival plan. Fifteen calm minutes can protect the first song.

Build the set around a shared clock.

The set includes durations, breaks, transitions, and the breath between songs. Give everyone the same run-of-show early enough to notice an odd handoff before it becomes a stage problem.

Surface the invisible cue.

A hard stop, a count-in, a patch switch, or an alternate ending is invisible until it matters. Write down the cue that makes each difficult song feel easy.

Leave one note for the next show.

Mark the transition that landed and the thing that felt rushed. The last set holds better information than memory does.

Use this next time
  • Confirm final order, runtime, and breaks.
  • Verify keys, capos, charts, and special gear.
  • Confirm arrival time, parking, and load-in details.
  • Carry one useful note forward.

Memory note / 03

Do not let a great rehearsal evaporate.

A rehearsal can contain useful evidence: a changed key, a cue that finally landed, a bridge that still runs away, or a harmony that needs another pass. The goal is not more note-taking. It is a small, usable memory.

Keep the decision, not the transcript.

Save the arrangement, tempo, ending, or order that now counts. No one needs a word-for-word record of a two-hour room.

Make trouble spots specific enough to practice.

“Bridge needs work” is too broad. “Bridge—tempo pushes after the second vocal line” gives the band something tangible to hear.

Anchor the note to a moment.

A recording timestamp turns a memory into something anyone can revisit on the drive to the next rehearsal.

Use this next time
  • Save the version that now counts.
  • Name one trouble spot precisely.
  • Capture a cue, harmony, or ending.
  • Mark the recording moment that proves what happened.

Band note / 04

Your band’s hidden job descriptions.

Someone sends the reminder. Someone knows the current key. Someone remembers that the bridge changed. These roles are not glamorous, but they are why bands keep making the drive.

The Keeper holds the thread.

The Keeper carries dates, details, decisions, and reminders. The healthiest band is not the one without a Keeper; it is the one that does not make one person carry everything alone.

The Translator makes feedback playable.

They ask, “Do we mean push the tempo, or change the entrance?” Their questions keep feedback practical and make hard conversations land softly.

The Evidence Keeper captures the moment of agreement.

A recording, chart mark, or concise note prevents an old argument from returning as a new creative difference.

Use this next time
  • Notice who carries dates, setlists, and reminders.
  • Name one task that can be shared.
  • Agree where decisions and current versions live.
  • Thank the person carrying invisible work.

Stage note / 05

A setlist should have a shape.

A setlist is not an inventory of songs you know. It is the path you give a room through the night. A shared reason for the order lets the stage stay responsive without becoming uncertain.

Choose the first promise.

The opener tells the room what kind of night it is. It does not need to be the fastest song. It needs to make the next song easier.

Build in turns, not only peaks.

Let the set breathe: a change in groove, a familiar hook, a chance to listen, then another rise. Shape is attention management.

Mark the places where the list can bend.

Identify the optional song, cuttable verse, or flex break before the night gets late. Flexibility works when everyone knows where it lives.

Use this next time
  • Name the opener and what it promises.
  • Mark energy turns after every few songs.
  • Confirm recovery moments and instrument changes.
  • Share the final set before load-in.

Band note / 06

The group text is not the problem. The missing decision is.

The group text is where a band talks. It should not be the only place a band remembers. The messages are evidence that a decision happened somewhere and never got a stable home.

Separate talking from deciding.

Conversation is supposed to wander. Decisions should not. State an agreed key, ending, date, set order, or arrival plan in one clean sentence.

Give a decision an owner and a date.

“We should probably…” is not a decision. Naming the next action keeps good intentions from becoming invisible work.

Close the loop in public.

When something changes, say what changed and where the current version lives. A two-line update can save four people from preparing the wrong thing.

Use this next time
  • Pull one current decision out of the group chat.
  • Write it for a late-arriving player.
  • Name the next owner and date.
  • Link the current chart, set, recording, or calendar detail.

Room note / 07

One song. One current version.

A song becomes expensive when every player practices a different memory of it. The original recording, a version learned at home, and the arrangement settled two rehearsals ago can quietly become three different songs.

Choose the source that wins.

For each active song, decide what counts as current: a live recording, chart, reference track, or rehearsal capture. Give a player who was absent a confident place to begin.

Record changes that alter preparation.

A changed key, form, intro cue, tempo feel, harmony split, cut verse, or ending deserves a clear record.

Retire old versions clearly.

Old links and old charts make uncertainty feel like a player mistake. Label the current source and take superseded versions out of the active path.

Use this next time
  • Choose a song with too many versions.
  • Name the single source that counts.
  • Record key, form, tempo feel, and ending.
  • Retire the version that should no longer be practiced.

Stage note / 08

The day-before-show message.

The day before a show is a bad time to discover that someone has the wrong call time, a missing chart, or no idea who is bringing the extension cord. A useful final message does not create anxiety. It removes it.

Start with the clock.

Put arrival, load-in, soundcheck, first set, breaks, and finish time in a sequence anyone can scan. “Be there around seven” is not a schedule.

Include the details that become urgent in a parking lot.

Venue contact, parking, load-in entrance, payment detail, and special gear all seem small until they are not.

End with a clean readiness ask.

Ask each player to confirm they have seen the note and flag one problem now—not after arrival.

Use this next time
  • Send the full arrival-to-finish sequence.
  • Include venue, contact, parking, and load-in detail.
  • Link the final setlist and any change.
  • Ask every player to confirm readiness.
