Why jam bands use it

Built for a deep, rotating repertoire.

Jam bands don't play the same 12 songs every night. GrooveLinx is built for a big catalog that rotates — and sets that get rebuilt every show.

🎵 Big catalog

Hundreds of songs, structured and searchable

Active vs. library status, per-song key, BPM, structure, lyrics, and reference recordings. Your whole book in one shared place instead of a spreadsheet and a Drive folder.

📋 Sets that rotate

Reusable, versioned setlists per gig

Build a set, reorder by drag, tie it to the gig on your calendar. Versioned so last weekend's set doesn't overwrite next weekend's — and Stage View reads from it directly.

🎚 Learn the jam

Stems to isolate any part

Self-hosted Demucs separation pulls drums, bass, keys, guitar and vocals out of a recording so you can practice your part with — or without — the rest of the band.

📊 Know what's ready

Per-song, per-member readiness

See which tunes are stage-ready, which are still woodshedding, and which haven't been touched in a month — so the set you build is the set you can actually play.
