For wedding bands

“The dep needs the book by Friday.”

“The client just changed the first dance.”

“Which version of the run of show is current?”

There is no margin on Saturday.

Weddings don’t give second chances. Every chart, every cue, every version — current, offline, on every stand.

What keeps getting lost

Which run of show is the real one.

The key the dep needs it in.

The client’s do-not-play list.

The cue into the first dance.

Great bands don’t lose songs. They lose memories.

Memory

One current version of everything — the book a dep can actually learn from by Friday.

Preparation

Subs and deps walk in Saturday-ready. No 90-minute phone briefings.

Synchronization

The whole band reads from the same truth — cues, keys, and the changes the client made on Wednesday.

Trust

Reliability is the floor: offline-first, because venue wifi is a rumor.

Flow
